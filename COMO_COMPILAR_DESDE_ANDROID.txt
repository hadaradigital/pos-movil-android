POS MÓVIL - APK NATIVA CON BLUETOOTH

Esta versión NO debe compilarse con APKForge.

OPCIÓN RECOMENDADA DESDE EL SAMSUNG A04: GitHub Actions

1) Entra a GitHub desde Chrome y crea un repositorio NUEVO (puede ser privado).
2) Descomprime este ZIP.
3) Sube TODO el contenido de la carpeta POS_Movil_Android al repositorio, conservando carpetas.
4) En el repositorio entra a la pestaña Actions.
5) Selecciona "Compilar APK".
6) Pulsa "Run workflow".
7) Espera a que termine en verde.
8) Abre la ejecución terminada y baja hasta "Artifacts".
9) Descarga "POS-Movil-Bluetooth-debug".
10) Dentro estará app-debug.apk. Instálala en el Samsung A04.

Si GitHub te muestra que las Actions no están habilitadas, entra a Settings > Actions > General y permite las Actions del repositorio.

ALTERNATIVA: AndroidIDE

AndroidIDE puede abrir proyectos Gradle existentes directamente en Android. El proyecto usa Android Gradle Plugin 8.7.3, compatible con la exigencia de AGP 7.2+ indicada por AndroidIDE. El proyecto AndroidIDE original está archivado/no mantenido, por lo que GitHub Actions es la opción preferida.

IMPRESORA

Antes de imprimir, vincula la impresora desde Ajustes > Bluetooth. Dentro del POS: Configuración del ticket > Impresora Bluetooth > selecciona la impresora.

La primera versión está pensada para Bluetooth Classic (SPP) + ESC/POS. Cuando compres la impresora de 80 mm, dime marca y modelo para adaptar codificación, ancho de caracteres, corte y funciones específicas.
