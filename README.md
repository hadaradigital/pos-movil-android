# POS Móvil Android

APK nativa con WebView + puente JavaScript/Android para Bluetooth Classic (SPP) y ESC/POS.

- Android target SDK 35
- Java 17
- Android Gradle Plugin 8.7.3
- Impresión térmica 58/80 mm mediante comandos ESC/POS básicos
- Selección de impresora Bluetooth vinculada
- Persistencia local del POS mediante localStorage

No requiere una biblioteca externa de impresión.
